# GRAVE — The First Onchain Last Will Protocol

Landing page for **GRAVE**, an onchain last-will protocol deployed on Robinhood Chain. Non-custodial smart contract vaults execute inheritance automatically once proof-of-life checks lapse — no probate, no lawyers, no single point of failure.

## Stack

Static site, no build step: `index.html`, `css/style.css`, `js/main.js`.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
